# Contact Management System (C++)

A C++ console application that manages contact information using a Linked List data structure.

## Features
- Add new contacts (Name, Phone Number, Email)
- Search for contacts
- Update or delete existing contacts
- Save and load contacts from a file (`contacts.txt`)

## Data Structures Used
- **Linked List:** Used for efficient dynamic memory management and node operations for contact entries.

## How to Run
1. Clone this repository or download the source files (`main.cpp`, `LinkedList.cpp`, `LinkedList.h`, `contacts.txt`).
2. Open the files in any C++ IDE (Code::Blocks, Visual Studio, VS Code, or Dev-C++).
3. Compile and run `main.cpp`.
